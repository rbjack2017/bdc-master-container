BDC Playbooks

New Lead Playbook
  • Send New Lead Email + Text + Voicemail
  • Follow-up within 2 hours
  • Day 2: Quiet Lead Text
  • Day 3–7: Alternating follow-up attempts
Appointment Playbook
  • Confirm appointment time + date
  • Send reminder text
  • Prepare vehicle before arrival
Price Playbook
  • Send Price Request Email + Text
  • Clarify budget + timeline
  • Offer similar options if needed
Trade Playbook
  • Gather VIN, miles, photos
  • Explain appraisal process
  • Set expectations for value range
Quiet Lead Playbook
  • Send soft nudge text
  • Alternate communication channel
  • Offer help or alternatives
Sold Redirect Playbook
  • Notify customer vehicle sold
  • Offer similar alternatives
  • Ask about flexibility (color, trim, mileage)
Long-Term Follow-Up (30 / 60 / 90 Days)
  • 30-Day: Check-in + offer help
  • 60-Day: Provide updated inventory
  • 90-Day: Final follow-up + close file
