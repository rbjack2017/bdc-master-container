Fresh Start Playbook

Messaging and workflows for customers with credit challenges who are exploring Fresh Start options.

Overview

This module focuses on empathetic, solution‑oriented messaging for credit‑challenged customers, explaining lender options, online applications, and how Fresh Start helps them get dependable transportation and rebuild credit.

Standards

  • Acknowledge credit concerns without judgment.
  • Explain that you work with many lenders specializing in different situations.
  • Guide customers to the online application and next steps clearly.

Examples

Use the Fresh Start / credit issue scripts and any dedicated Fresh Start templates in your library as examples.
