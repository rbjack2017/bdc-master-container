Alternative Options

How to present strong alternative vehicles that match the customer’s needs and keep the conversation moving.

Overview

Offering alternatives is a core redirect skill. This module teaches how to select the right vehicles, present them clearly, and guide customers toward the next step without pressure.

Standards

  • Choose alternatives based on must‑haves.
  • Present 2–3 options maximum.
  • Ask which one fits best before scheduling a visit.

Examples

“Based on what you liked about the {{Vehicle}}, here are three similar options: {{Option1}}, {{Option2}}, {{Option3}}. Which one fits best for you?”
