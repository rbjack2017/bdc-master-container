CRM Basics

Introduction to CRM navigation, lead management, tasks, notes, and follow‑up structure.

Overview

This module teaches new team members how to navigate the CRM, manage leads, complete tasks, write notes, and follow the Day 1–7 workflow structure.

Standards

  • Every action must generate a next task.
  • Notes must be clear, specific, and action‑oriented.
  • Follow the Day 1–7 workflow for all new leads.

Examples

Good note: “Called twice, left voicemail, sent Day 1 email. Next task set for tomorrow morning.” Bad note: “Called. Left VM.”
