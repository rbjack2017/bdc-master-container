Tools Setup

How to set up all required tools: CRM login, phone system, email signature, templates, and dashboards.

Overview

This module walks new team members through setting up all required tools: CRM access, phone system login, email signature, template library access, and dashboard navigation.

Standards

  • Ensure CRM login is active and verified.
  • Set up email signature using approved format.
  • Bookmark all dashboards for quick access.

Examples

“Your email signature must include your name, role, store, and direct line.” “Bookmark the Master Dashboard, Playbook Dashboard, and CRM Tasks Dashboard.”
