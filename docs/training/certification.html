Certification Module

The Certification Module outlines the BDC Certification Program (BDCCR). It defines the levels, requirements, timelines, and advancement structure for all BDC reps.

1. Certification Levels

BDCCR Level 1 — Foundations

  • Complete Governance Module
  • Complete CRM Tasks Module
  • Complete Workflows Module
  • Pass Level 1 Knowledge Check

BDCCR Level 2 — Proficiency

  • Complete Objections Module
  • Complete Templates Module
  • Meet KPI benchmarks
  • Pass Level 2 Knowledge Check

BDCCR Level 3 — Mastery

  • Complete QA Training Module
  • Complete Compliance Module
  • Maintain 70+ QA score
  • Pass Level 3 Certification Exam

2. Certification Requirements

  • All modules must be completed
  • All knowledge checks must be passed
  • All KPIs must meet minimum benchmarks
  • All workflow rules must be followed

3. Advancement Timeline

  • Level 1 → within first 30 days
  • Level 2 → within 60–90 days
  • Level 3 → within 6–12 months

4. Certification Benefits

  • Increased opportunity access
  • Higher performance bonuses
  • Priority routing
  • Leadership development eligibility

5. Certification Summary

The BDCCR program ensures reps develop the skills, knowledge, and consistency needed to perform at the highest level in the BDC.
