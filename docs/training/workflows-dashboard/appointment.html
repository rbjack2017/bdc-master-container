Appointment Workflow

How to set appointments, confirm them, and prevent no‑shows using simple, clear messaging.

Overview

The Appointment Workflow teaches how to set strong appointments, confirm them properly, and reduce no‑shows using one‑question messaging and clear expectations.

Standards

  • Offer two time options.
  • Send confirmation message immediately.
  • Use a soft reminder before the appointment.

Workflow Steps

Step 1: Offer two time options. Step 2: Confirm with name + time + store. Step 3: Send reminder. Step 4: Follow up if they miss the appointment.

Examples

“Would today or tomorrow work better?” “Just a quick reminder — still good for 3 PM?”
