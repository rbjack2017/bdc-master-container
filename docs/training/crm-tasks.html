CRM Tasks & Follow-Up Discipline Module

This module defines the exact CRM task structure, follow-up timing, documentation standards, and discipline required to maintain consistent customer engagement and workflow accuracy.

1. Purpose of CRM Tasks

  • Ensure no customer is forgotten
  • Maintain consistent follow-up timing
  • Support workflow accuracy
  • Provide clear next steps for every interaction
  • Enable accountability and transparency

2. Core CRM Task Rules

Daily Task Requirements

  • All tasks must be completed on the day they are due
  • No skipping tasks
  • No deleting tasks
  • No pushing tasks forward without reason

Task Creation Rules

  • Every customer interaction must generate a next task
  • Tasks must reflect the correct workflow step
  • Tasks must be scheduled at the correct interval

3. Task Timing Standards

Day 1

  • Immediate call attempt
  • OEM-compliant Day 1 email
  • One compliant text
  • Next task: Day 2 follow-up

Day 2–6

  • Daily call attempt
  • Daily email or text based on workflow
  • Next task: Next day follow-up

Day 7

  • Final call attempt
  • Final email
  • Inactivate lead
  • Correct dead note: “Due to Processes – Non-Responsive”

4. CRM Documentation Standards

Every interaction must be documented clearly and accurately.

Required Note Elements

  • Purpose of the interaction
  • Outcome of the interaction
  • Customer’s response (if any)
  • Next step
  • Task created

Prohibited Notes

  • “Called”
  • “Left VM”
  • “Follow-up”
  • “Sent email”

5. Task Accuracy Requirements

  • Correct task type (call, email, text)
  • Correct timing (same day or next day)
  • Correct workflow step
  • Correct customer status

6. Task Discipline & Accountability

Task discipline is mandatory. Failure to complete tasks results in workflow breakdown and customer neglect.

Minor Violations

  • Late task completion
  • Missing next task
  • Incorrect task type

Major Violations

  • No tasks completed for the day
  • Skipping workflow steps
  • Incorrect inactivation
  • Tasks created after inactivation

7. Task Quality Standards

  • Tasks must be clear and actionable
  • Tasks must match the customer’s situation
  • Tasks must follow the workflow exactly
  • Tasks must be created immediately after each interaction

8. CRM Task Summary

CRM tasks are the backbone of BDC follow-up discipline. They ensure consistency, accountability, and workflow accuracy. Every customer deserves a clear next step, and every rep must maintain task discipline daily.
