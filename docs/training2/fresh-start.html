Fresh Start Module

The Fresh Start Module teaches reps how to handle opportunities that require a reset — situations where communication has stalled, the customer is confused, or the workflow needs to be restarted cleanly.

1. What Is a Fresh Start?

A Fresh Start is a structured reset used when an opportunity becomes stuck or misaligned. It allows reps to restart communication cleanly and professionally.

  • Customer hasn’t responded in several days
  • Customer received mixed or unclear communication
  • Workflow steps were missed
  • Opportunity needs a clean re‑engagement

2. Fresh Start Rules

  • Use approved Fresh Start templates only
  • Do not reference past mistakes or confusion
  • Keep tone positive and forward‑focused
  • Ask one simple question to restart engagement

3. Approved Fresh Start Language

These templates help reset communication without drawing attention to previous issues.

  • “Hi {{First Name}}, just checking in — are you still considering the {{Vehicle}}?”
  • “Happy to help with any questions you have.”
  • “Would you like to pick up where we left off?”

4. When to Use a Fresh Start

  • After missed tasks
  • After unclear communication
  • After long gaps in customer response
  • When customer engagement needs a reset

5. Fresh Start Workflow

  • Send Fresh Start text
  • Send Fresh Start email
  • Document everything in CRM
  • Resume workflow from Day 1 if needed

6. Fresh Start Summary

Fresh Starts allow reps to recover stalled opportunities, maintain professionalism, and re‑establish clear communication with customers.
