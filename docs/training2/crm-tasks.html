CRM Tasks Module

The CRM Tasks Module defines how reps manage, complete, and document tasks inside the CRM. It ensures consistency, accuracy, and accountability across all customer interactions.

1. Task Discipline

  • All tasks must be completed on time
  • Tasks must be completed in the correct order
  • Tasks must never be skipped or ignored
  • Tasks must be completed before responding to customers

2. Documentation Standards

  • Every customer interaction must be logged
  • Notes must be clear, accurate, and professional
  • Source logging must be correct
  • All communication must be documented immediately

3. Workflow Timing

  • Day 1 tasks must be completed within 10 minutes
  • Follow-up tasks must be completed exactly as scheduled
  • Inactivation must occur on Day 7
  • No tasks after inactivation

4. CRM Task Summary

CRM tasks ensure workflow accuracy, customer satisfaction, and compliance with dealership standards.
